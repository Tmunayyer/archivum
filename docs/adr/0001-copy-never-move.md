# Copy, never move

Archivum always copies a file to the destination and leaves the source untouched — it never moves, renames in place, or deletes. A tool that batch-relabels media is one mistyped field away from making originals unfindable, and the recovery cost is total. We accept the duplicated disk usage and the manual cleanup that follows a run in exchange for having no destructive path in the codebase at all.
